v1.10.0
- 新增局域网文件互传：同一 Wi-Fi 下的设备可通过浏览器上传、下载、浏览和新建文件夹。
- 两台运行本应用的设备会自动发现，可在应用内浏览对方共享目录并上传、下载文件。
- SMB/SFTP 和局域网互传中的音频支持直接流式播放，播放时自动缓存到本地。
- 网页支持拖拽上传、多文件上传、中文文件名和 Range 下载。
- 设置中新增“局域网互传”，也可在任意文件夹菜单中选择共享当前目录。
- 互传使用随机访问令牌和路径穿越防护，仅共享指定目录。

v1.9.0
- 包名更改为 io.github.inwins.filebrowser，面向 GitHub 发布。
- 由于包名变化，旧版本 com.example.filebrowser 的设置和数据不会自动迁移。
- 无歌词时歌词按钮不再可点击，并显示为禁用状态。

v1.8.0
- 优化 SMB/SFTP 添加与编辑对话框：分区布局、协议切换、测试连接、密码显隐和固定底部操作栏。
- 上传/下载对话框新增百分比、进度条、速度、剩余时间和实时字节数。
- 剪贴板栏支持在本机与网络存储之间快速切换。
- 本机文件页顶栏新增“网络”入口，远程文件页顶栏新增“本机”入口。
- 修复 SMB 对话框内容过长时保存按钮被挤出屏幕的问题。

v1.7.0
- 新增回收站：本地文件删除时默认移入回收站，可恢复、永久删除或清空。
- 设置中新增“删除时移入回收站”开关。
- 新增内置视频播放器，支持本地视频及缓存后的远程视频。

v1.6.1
- 通过本机流媒体接口加载远程图片/视频缩略图。
- 标签与收藏现在也支持远程 SMB/SFTP 路径。
- 允许本机回环流媒体接口使用明文 HTTP。

v1.6.0
- SFTP 支持私钥登录，可选 SHA-256 主机指纹校验。
- SMB 支持访客/匿名登录和域账号。
- 压缩包预览与解压：ZIP、7Z、RAR、TAR、TAR.GZ、GZ。
- 支持 AES 加密 ZIP 的解压与创建，以及分卷 ZIP 创建。
- 存储清理：重复文件、大文件、缓存清理。
- 文件哈希：MD5、SHA-1、SHA-256。
- 标签、收藏、颜色标记、置顶，收藏/置顶显示在首页。
- 本地图片和视频缩略图。
- 远程缩略图暂未实现，远程文件使用类型图标。

v1.5.0
- 远程 SMB/SFTP 目录支持多选，以及复制、剪切、删除。
- 远程剪贴板可粘贴到另一个远程目录或本地目录；本地文件也可粘贴到远程目录。
- 新增本机 HTTP 流媒体接口（支持 Range 拖动），视频/音频可直接交给 VLC 等外部播放器，无需先完整下载。
- 远程媒体新增“用其他应用播放”和“复制流媒体地址”。
- 流媒体通过前台服务运行，通知栏可停止。
- 流媒体服务仅监听 127.0.0.1。

v1.4.1
- 单击远程文件改为弹出操作菜单，不再直接下载，避免误触。
- SMB/SFTP 下载和上传增加百分比进度条。
- 下载/上传支持取消，取消后会删除未完成的临时文件。

v1.4.0
- 新增音频歌词显示。
- 自动读取音频旁边的同名 .lrc 文件，支持时间轴同步、当前行高亮、自动滚动、元数据标签和 offset 偏移。
- 支持本地、Root、SMB、SFTP 音频；远程歌词会随音频一起缓存。
- 点击播放界面的歌词按钮可在封面和完整歌词之间切换，封面页也会显示当前歌词行。

v1.3.1
- 修复退出播放界面后，底部迷你播放条与系统虚拟按键重叠的问题。
- 播放界面和迷你播放条现在都会避开系统底部导航区域。

v1.3.0
- 新增应用内音频播放器：专辑封面、标题/艺术家/专辑、播放列表、进度拖动、上一首/下一首和小型播放条。
- 点击本地、Root、SMB 或 SFTP 中的音频文件即可在应用内播放；远程音频会先缓冲到本地缓存再播放。
- 浏览文件时音乐继续播放，可从底部播放条暂停或关闭。

v1.2.1
- 应用更名为“文件浏览器”，移除所有 CX 标识。
- 新的包名：com.example.filebrowser。旧包名的设置不会自动迁移。

v1.2.0
- 新增 Root 访问：在设置中开启并授予超级用户权限后，可浏览 /data、/system 等受限目录。
- Root 文件操作：新建、重命名、删除、与普通存储之间复制；Root 文件会复制到缓存后预览。
- 新增 SMB2/SMB3 网络存储：添加/编辑/删除服务器，浏览共享目录，上传、下载、重命名、删除、查看属性。
- 新增 SFTP 网络存储（密码登录），支持相同的文件操作。
- 新增“网络”标签页，密码使用加密存储。
- TTS 现在每次从屏幕当前可见的内容开始朗读。
- TTS 改为逐段顺序朗读，支持自动下一章、暂停/继续，并提供语音引擎诊断。
- 修复并完善阅读设置面板。

v1.1.0
- 新增 TXT 阅读器，自动识别“第X章 / 第X卷 / 第X节”、Chapter N、序章 / 番外 / 尾声以及 Markdown 标题等章节格式。
- 新增目录列表，可点击章节快速跳转。
- 自动保存阅读进度，重新打开书籍时自动恢复位置。
- 新增按书籍保存的书签：添加、跳转、删除。
- 新增 TTS 语音朗读：从当前页开始、暂停/继续、停止、读完自动下一章、朗读语速调节。
- 新增阅读设置：字号、行距、纸张 / 羊皮纸 / 护眼 / 深色主题。
- 阅读器中可直接切换到文本编辑。
- 改进文本编码识别（UTF-8 / GBK），支持最大 30 MB 的文本。
- 新增应用内更新日志。

v1.0.0
- 首个版本：存储首页、文件浏览、分类、搜索、复制/剪切/粘贴、重命名、删除、ZIP 压缩/解压、图片查看器、文本编辑器、应用管理、存储分析、书签和最近记录。
