v1.6.0
- SFTP private-key authentication and optional SHA-256 host fingerprint verification.
- SMB guest/anonymous login and domain names.
- Archive preview and extraction for ZIP, 7Z, RAR, TAR, TAR.GZ and GZ.
- AES-encrypted ZIP creation and extraction; multi-volume ZIP creation.
- Storage cleaner: duplicate files, large files and cache cleaning.
- File hashes: MD5, SHA-1 and SHA-256.
- Tags, favorites, colors and pinned items on the Home screen.
- Local image and video thumbnails.
- Remote thumbnails are not implemented yet; remote entries use type icons.

v1.5.0
- Added multi-select in remote SMB/SFTP directories with copy, cut and delete.
- Remote clipboard can paste to another remote folder or to local storage; local files can also be pasted into remote folders.
- Added a loopback HTTP streaming server with Range support, so videos/audio can be handed to VLC or other players without downloading first.
- Added "Play in another app" and "Copy stream URL" actions for remote media.
- Streaming runs in a foreground service with a notification and a stop action.
- The streaming server listens on 127.0.0.1 only.

v1.4.1
- Tapping a remote file now opens an action dialog instead of downloading immediately, preventing accidental downloads.
- Added a determinate progress bar with percentage for SMB/SFTP downloads and uploads.
- Remote downloads and uploads can be cancelled; partial files are removed.

v1.4.0
- Added lyrics display for audio playback.
- Reads matching .lrc files next to the audio file; supports synced timestamps, current-line highlighting, auto-scroll, metadata tags and offset.
- Works for local, root, SMB and SFTP audio; remote .lrc files are fetched alongside the cached audio.
- Tap the lyrics icon to toggle between cover art and full lyrics. The current line also appears on the cover screen.

v1.3.1
- Fixed the mini player bar overlapping the system navigation buttons after leaving the audio player.
- The audio player and mini player now respect the bottom system inset.

v1.3.0
- Added an in-app audio player with album art, title/artist/album, playlist, seeking, previous/next and a mini player.
- Tapping an audio file on local storage, root paths, SMB or SFTP opens the built-in player. Remote audio is buffered to the local cache before playback.
- Playback continues while browsing; close it from the mini player.

v1.2.1
- Renamed the app to File Browser and removed all CX branding.
- New package name: com.example.filebrowser. Settings from older package versions are not migrated automatically.

v1.2.0
- Added root access: enable it in Settings, grant superuser permission, then browse restricted paths such as /data and /system.
- Root operations: create, rename, delete and copy between root and normal storage; root files are copied to cache for preview.
- Added SMB2/SMB3 network storage: add, edit and delete servers, browse shares, upload, download, rename, delete and view properties.
- Added SFTP network storage with password authentication and the same file operations.
- Added a Network tab with encrypted password storage.
- TTS now starts from the text currently visible on screen.
- TTS speaks sequentially and supports automatic next chapter, pause/resume and engine diagnostics.
- Reader settings sheet fixed and improved.

v1.1.0
- Added a TXT reader with automatic chapter detection for "Chapter N", "第X章 / 第X卷 / 第X节", prologue/epilogue and Markdown headings.
- Added a chapter list with jump-to-chapter navigation.
- Reading progress is saved automatically and restored when a book is reopened.
- Added per-book bookmarks: add, jump and delete.
- Added text-to-speech: start from the current page, pause/resume, stop, automatic next chapter and adjustable speech rate.
- Added reading settings: font size, line spacing and paper / sepia / eye-care / dark themes.
- Open the text editor directly from the reader.
- Improved text encoding detection (UTF-8 / GBK) and large-file support up to 30 MB.
- Added an in-app changelog.

v1.0.0
- First release: storage dashboard, file browser, categories, search, copy/cut/paste, rename, delete, ZIP compress/extract, image viewer, text editor, app management, storage analysis, bookmarks and recent files.
